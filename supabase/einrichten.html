Supabase einrichten

  1. Tippe unten auf „SQL kopieren“.
  2. Wechsle zu Supabase → SQL Editor, leere das Textfeld und füge ein (Finger gedrückt halten → Einsetzen).
  3. Tippe auf Run und bei der Warnung auf Run query.

Supabase SQL Editor öffnen

Tipp: In der App findest du das auch unter ☰ → 🛠 Admin-Menü → „Datenbank (Supabase)“ – dort siehst du auch, ob alles aktuell ist.

Dich als Admin eintragen (einmalig)

  1. Erst das große SQL oben ausführen.
  2. Hier die E-Mail deines Level-Up-Kontos eintragen und auf „Admin-Befehl kopieren“ tippen.
  3. In Supabase → SQL Editor → New query einfügen → Run.
  4. In der App einmal abmelden und wieder anmelden: Im Menü ☰ erscheint 🛠 Admin-Menü.

E-Mails einrichten (einmalig, ca. 5 Minuten)

Danach bekommen neue Nutzer eine deutsche Mail im Level-Up-Look mit einem großen Knopf, und der Link führt direkt in die App – nicht mehr auf supabase.co.

  1. Supabase → Authentication → URL Configuration: bei Site URL eintragen:
    https://lukbru4.github.io/Gym-/
    Bei Redirect URLs dieselbe Adresse hinzufügen → Save.
  2. Supabase → Authentication → Emails (bzw. Email Templates). Für jede Vorlage unten: Reiter in Supabase öffnen, Betreff kopieren → bei „Subject“ einfügen, Text kopieren → bei „Message body“ alles ersetzen → Save.

Test: Registriere dich mit einer zweiten E-Mail-Adresse – die Mail sollte jetzt so aussehen wie in der Vorschau.

Später: eigener Absender (braucht eigene Domain)

Bis dahin steht als Absender noch „Supabase Auth“. Außerdem verschickt Supabase ohne eigenen Mail-Dienst nur sehr wenige Mails pro Stunde – bei vielen neuen Nutzern auf einmal kommen manche Mails dann nicht an.

  1. Domain kaufen, z. B. bei IONOS, Strato oder Cloudflare (ca. 1 € pro Monat), etwa levelup-app.de.
  2. Kostenloses Konto bei einem Mail-Dienst anlegen, z. B. Brevo (300 Mails/Tag gratis) oder Resend.
  3. Dort die Domain hinzufügen und die angezeigten DNS-Einträge beim Domain-Anbieter eintragen (dauert bis zu einem Tag).
  4. Supabase → Authentication → SMTP Settings → „Enable custom SMTP“: Absender hallo@deine-domain.de, Name Level Up, dazu Server, Port, Benutzer und Passwort vom Mail-Dienst → Save.

Die Zugangsdaten trägst nur du in Supabase ein – nirgends sonst und nicht im Chat.
